# Portfolio

## Fill the placeholders
Every grey box is a `<div class="ph"></div>`. Put an image or video inside it:
  <div class="ph"><img src="assets/work/dolphin.jpg" alt="Dolphin"></div>
  <div class="ph"><video src="assets/work/ecozen.mp4" autoplay muted loop playsinline></video></div>

Clip rows are generated in the script at the bottom of index.html. To use real clips, replace the
`tiles(5)` lines with your own list of <div class="ph"><video ...></video></div> (repeat the list twice so it loops seamlessly).

Also replace you@example.com, the LinkedIn/Instagram links, and add assets/resume.pdf.

## Publish on GitHub Pages
1. Create a repo (name it yourusername.github.io for a root URL).
2. Upload everything in this folder.
3. Settings → Pages → Deploy from a branch → main → /root.
4. Live at https://yourusername.github.io shortly after.
